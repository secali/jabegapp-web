> **Modern web portal and analytics dashboard for the Malaga Traditional Rowing League (Liga de Jábegas).**

---

## 🎯 Overview

The web counterpart to JábegApp, providing league administrators, journalists, and enthusiasts with an interactive web portal featuring responsive regatta calendars, dynamic leaderboard visualizations, boat specifications, and historical championship archives.

### 🌟 Features
- **Responsive Single Page Application**: Angular component hierarchy optimized for mobile and desktop screens.
- **Dynamic Leaderboards**: Live points calculation and ranking tables.
- **Club & Boat Profiles**: Rich media profiles for traditional rowing teams and artisan wooden boats.

## 🚀 Development Server

```bash
cd angular-jabegapp
npm install
npm start
```
Navigate to `http://localhost:4200/` in your browser.
